# Great Talk Africa

The EA → Chief of Staff workbook and monthly mentorship site for Abraham Otieno.

Static, multi-page, no build step — plain HTML/CSS/JS deployed via GitHub Pages.

## Pages

- `index.html` — Home
- `workbook.html` — The workbook (Module 1 free)
- `mentorship.html` — Mentorship sessions
- `quiz.html` — Quick Gut Check quiz
- `for-leaders.html` — Bonus section for founders/CEOs
- `faq.html` — FAQ
- `about.html` — About Abraham
- `contact.html` — Contact
- `404.html` — Custom not-found page

Shared styles/scripts live in `assets/`.
